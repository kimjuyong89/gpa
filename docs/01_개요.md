# 개요

오리지널 무협 세계에서 정해진 주인공이 문파·정사·인연을 스스로 골라 가며 강호를 누비는, 2D 탑다운 턴제 파티 RPG.

## 확정 사항

| 항목 | 결정 |
|---|---|
| 가제 | 강호유랑기(江湖流浪記). 표기는 한글 + 한자 |
| 장르 | 무협 RPG, 자유도 중심 |
| 세계관 | 오리지널 무협. 기존 IP의 인물·설정은 쓰지 않는다 |
| 플랫폼 | PC 데스크톱 (Windows) |
| 엔진 | Unity 6.3 LTS (6000.3.27f1), URP 2D |
| 규모 | 장기 프로젝트, 마일스톤 단위로 진행 |
| 개발 체계 | 1인 개발 + 에셋 구매 |
| 시점 | 2D 탑다운 |
| 아트 | 수묵·한지 UI + 애니메이션풍 2D 캐릭터. 맵은 임시로 Ninja Adventure(CC0) 픽셀 아트 |
| 전투 | 대치형 턴제, 동료 파티 최대 3~4명 |
| 성장 | 내공 경지 돌파 + 무공 숙련도 + 수련 행동 |
| 월드 | 자유롭게 걷는 큰 지도(강호) + 마을 지역맵 |
| 스토리 | 메인 줄기 + 자유 행동, 다중 엔딩 |
| 시간 | 시간 개념 없음. 퀘스트 진행에 따라 세계가 변한다 |
| 주인공 | 고정 주인공. 이름·외형·초기 스탯은 플레이어가 정한다 |
| 대화·퀘스트 대본 | Ink |
| 출시 | 미정 |

## 자유도의 네 축

1. **오픈월드**: 강호 지도를 걸어 다니며 메인 줄기와 상관없이 탐험한다.
2. **문파 선택·배신**: 입문하거나 파문당하거나 다른 문파로 옮길 수 있고, 문파를 직접 세울 수도 있다. (문파 창설은 [기획])
3. **정사 성향·평판**: 정파/사파/마교 쪽 행보가 쌓여 NPC 반응, 열리는 퀘스트, 엔딩이 달라진다.
4. **인연·관계**: NPC와 사제, 의형제, 연인, 원수 관계를 맺고, 관계를 맺은 NPC가 동료가 된다. (M1은 호감도와 소육 합류까지 [구현])

## 코어 루프

```
강호를 걷는다 → 마을·장소에 들어간다 → 대화·의뢰·수련 → 전투 → 성장(경지·숙련도)
→ 평판·관계 변화 → 메인 줄기 진행
```
