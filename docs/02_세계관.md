# 세계관

| 항목 | 결정 |
|---|---|
| 시대 | 태평성대 이면의 강호. 나라는 안정되어 있지만 무림은 물밑에서 들끓는다 |
| 세력 | 정파 · 사파 · 마교 3파전에 관부가 얽힌다 |
| 무공 강도 | 중무협. 경공, 장풍, 검기 수준이고 최고수도 사람의 범주 안에 있다 |
| 톤 | 메인 줄기는 진지하게, 동료·일상 이벤트에는 유머를 넣는다 |
| 메인 갈등 | 다섯 조각으로 나뉜 비급 '무극진경'을 둘러싼 쟁탈전 |
| 주인공 | 출신 불명의 고아. 사실은 비급을 남긴 무극성의 후손 (3막 공개) |
| 관부 | 막후의 흑막. 황제가 반로환동을 얻으려고 쟁탈전을 일으켰다 (3막 공개) |

## 세력 구도

- **정파**: 명문정파 연합. 강호의 질서를 자처한다.
- **사파**: 실리를 좇는 문파·방회 연맹. 정파와 대립하지만 거래도 한다.
- **마교**: 공공의 적으로 낙인찍힌 세력. 쟁탈전에 뛰어든다.
- **관부**: 표면상 무림에 관여하지 않는다. 실제로는 쟁탈전을 뒤에서 조종한다.

문파별 내용은 [03_문파](03_문파.md).

## 비급 · 혈통 · 흑막

> 확정: 5조각 비급, 백 년 전 천하제일인, 주인공은 그 후손, 비급 내용은 무공 + 반로환동, 흑막은 황제 본인, 혈통은 3막 공개.
> 이름, 조각을 가진 곳, 복선은 초안이다.

**무극성(無極聖)**: 백 년 전 천하제일인. 정파·사파·마교 어디에도 속하지 않았고 본명은 전해지지 않는다.
- 플레이어가 주인공 이름을 정하므로 혈통은 성씨로 드러나지 않는다. 대신 **표식**(혈맥의 반응, 맡겨질 때 지니고 있던 물건)으로 증명한다.

**무극진경(無極眞經)**: 무극성이 남긴 비급.
- 담긴 것: 최고 무공 + **반로환동**(늙은 몸을 되돌리는 비법)
- 무극성은 자기 무공이 악용될까 두려워 비급을 다섯 조각으로 나눴다.

| 조각 | 가진 곳 | 비고 |
|---|---|---|
| 1 | 정파 연합 (소림사 장경각) | 정파 맹약의 증표로 맡겨졌다 |
| 2 | 사파 연맹 (만금전장 금고) | 사파의 자금줄이 담보처럼 쥐고 있다 |
| 3 | 마교 (법왕전) | 교리의 근원이라 여기고 집착한다 |
| 4 | 행방불명 | M1 장부 사건에서 단서가 나온다 |
| 5 | 행방불명 | 무극성의 은거지. 탐험의 최종 보상 |

**흑막: 황제**: 태평성대를 이룬 명군으로 칭송받지만 늙음과 죽음을 두려워한다. 원하는 것은 무공이 아니라 반로환동이다.
- 비밀 기구 **암룡위(暗龍衛)** 를 통해 조각의 행방을 흘려 쟁탈전을 일으켰다. 무림이 피를 흘리며 조각을 모으게 한 뒤 마지막에 거둬 가려 한다.
- 백련서원은 관부와 가까워서 암룡위의 단서를 흘리는 통로가 된다.

**복선 (제안)**: 주인공이 조각에 가까이 가면 내력이 공명한다. 처음에는 "체질이 특이하다" 정도로 넘어가고, 3막에서 혈통의 증거로 밝혀진다.

## 메인 줄기

1. **1막 — 백로진** [초안, 구현]: 대사형의 장부 사건에서 4번째 조각의 단서를 손에 넣는다. '無極' 상자가 경사(京師)로 보내졌다는 기록이 관부의 첫 복선이다. 자세한 내용은 [09_퀘스트](09_퀘스트.md).
2. **2막 — 쟁탈전** [기획]: 문파를 고르고 정사 세력 사이에서 조각을 쫓는다. 싸움이 커지고 암룡위의 그림자가 보이기 시작한다.
3. **3막 — 진실** [기획]: 혈통과 흑막이 한꺼번에 드러나고 마지막 선택을 한다.
   - 최종 선택 후보: 비급을 파괴한다 / 직접 익힌다 / 한 세력에 넘긴다 / 황제와 거래한다

## 엔딩 분기 기준 [기획]

네 가지의 조합으로 갈린다.

- 정사 성향 (정파/사파/마교)
- 소속 문파 (남은 문파, 또는 직접 세운 문파)
- 인연 (연인·의형제가 누구인지, 동료의 생존 여부)
- 메인 줄기 마지막 사건에서의 핵심 선택
