# 세계관

| 항목 | 결정 |
|---|---|
| 시대 | 태평성대 이면의 강호. 나라는 안정되어 있지만 무림은 물밑에서 들끓는다 |
| 세력 | 정파 · 사파 · 마교 3파전에 관부가 얽힌다 |
| 무공 강도 | 중무협. 경공, 장풍, 검기 수준이고 최고수도 사람의 범주 안에 있다 |
| 톤 | 메인 줄기는 진지하게, 동료·일상 이벤트에는 유머를 넣는다 |
| 메인 갈등 | 다섯 조각으로 나뉜 비급 '무극진경'을 둘러싼 쟁탈전 |
| 주인공 | 기억을 잃은 채 백로진 나루터에서 발견된다. 이름 말고는 아무것도 모른다. 사실은 비급을 남긴 무극성의 후손 (3막 공개) |
| 관부 | 막후의 흑막. 황제가 반로환동을 얻으려고 쟁탈전을 일으켰다 (3막 공개) |

## 세력 구도

- **정파**: 명문정파 연합. 강호의 질서를 자처한다. 3막에서 **무림맹**을 세운다.
- **사파**: 실리를 좇는 문파·방회 연맹. 정파와 대립하지만 거래도 한다. 3막에서 **사도맹**을 세운다.
- **마교**: 공공의 적으로 낙인찍힌 세력. 쟁탈전에 뛰어든다.
- **관부**: 표면상 무림에 관여하지 않는다. 실제로는 쟁탈전을 뒤에서 조종한다.

문파별 내용은 [03_문파](03_문파.md).

## 비급 · 혈통 · 흑막

> 확정: 5조각 비급, 백 년 전 천하제일인, 주인공은 그 후손, 비급 내용은 무공 + 반로환동, 흑막은 황제 본인, 혈통은 3막 공개.
> 이름, 조각을 가진 곳, 복선은 초안이다.

**무극성(無極聖)**: 백 년 전 천하제일인. 정파·사파·마교 어디에도 속하지 않았고 본명은 전해지지 않는다.
- 플레이어가 주인공 이름을 정하므로 혈통은 성씨로 드러나지 않는다. 대신 **표식**으로 증명한다: 혈맥의 반응, 그리고 발견될 때 품에 있던 **낡은 옥패** [구현]. 뒷면 글자는 닳아 있고, 3막에서 "無極"으로 밝혀진다.
- **기억상실** [구현]: 게임은 주인공이 사흘 만에 객잔에서 깨어나는 장면으로 시작한다. 기억은 끝까지 돌아오지 않는다. 과거는 되찾는 것이 아니라 남들이 알려 주는 것이다 — 혈통은 3막에서 옥패와 혈맥의 반응으로 타인이 밝히고, 주인공은 그것을 믿을지 말지만 고른다. 일지 "잃어버린 기억"은 시작 상황의 기록일 뿐 해결해야 할 퀘스트가 아니다.

**무극진경(無極眞經)**: 무극성이 남긴 비급.
- 담긴 것: 최고 무공 + **반로환동**(늙은 몸을 되돌리는 비법)
- 무극성은 자기 무공이 악용될까 두려워 비급을 다섯 조각으로 나눴다.

| 조각 | 가진 곳 | 비고 |
|---|---|---|
| 1 | 정파 연합 (소림사 장경각) | 정파 맹약의 증표로 맡겨졌다 |
| 2 | 사파 연맹 (만금전장 금고) | 사파의 자금줄이 담보처럼 쥐고 있다 |
| 3 | 마교 (법왕전) | 교리의 근원이라 여기고 집착한다 |
| 4 | 행방불명 | M1 장부 사건에서 단서가 나온다 |
| 5 | 행방불명 | 무극성의 은거지. 탐험의 최종 보상 |

**흑막: 황제**: 태평성대를 이룬 명군으로 칭송받지만 늙음과 죽음을 두려워한다. 원하는 것은 무공이 아니라 반로환동이다.
- 비밀 기구 **암룡위(暗龍衛)** 를 통해 조각의 행방을 흘려 쟁탈전을 일으켰다. 무림이 피를 흘리며 조각을 모으게 한 뒤 마지막에 거둬 가려 한다.
- 백련서원은 관부와 가까워서 암룡위의 단서를 흘리는 통로가 된다.

**복선 (제안)**: 주인공이 조각에 가까이 가면 내력이 공명한다. 처음에는 "체질이 특이하다" 정도로 넘어가고, 3막에서 혈통의 증거로 밝혀진다.

## 메인 줄기

1. **1막 — 백로진** [초안, 구현]: 대사형의 장부 사건에서 4번째 조각의 단서를 손에 넣는다. '無極' 상자가 경사(京師)로 보내졌다는 기록이 관부의 첫 복선이다. 자세한 내용은 [09_퀘스트](09_퀘스트.md).
2. **2막 — 쟁탈전** [기획]: 문파를 고르고 정사 세력 사이에서 조각을 쫓는다. 싸움이 커지고 암룡위의 그림자가 보이기 시작한다.
3. **3막 — 맹(盟)** [기획]: 정사 성향에 따라 **무림맹** 또는 **사도맹**에 들어가 학원물로 흐른다. 혈통과 흑막은 맹 안에서 드러나고, 마지막 선택도 맹 안에서 한다.
   - 최종 선택 후보: 비급을 파괴한다 / 직접 익힌다 / 한 세력에 넘긴다 / 황제와 거래한다

### 3막 — 무림맹 · 사도맹 학원물 [기획]

2막 끝에 조각 네 개의 행방이 드러나고 각 세력이 사람을 모은다. 정파는 **무림맹**, 사파는 **사도맹**을 세워 젊은 고수를 "맹의 제자"로 거둬들인다. 주인공은 `정파 >= 사파`면 무림맹, 아니면 사도맹으로 들어간다. 마교 성향이 가장 높으면 사도맹에 **마교 잠입자**로 들어간다(같은 지도, 다른 사건).

| | 무림맹 (정파) | 사도맹 (사파) |
|---|---|---|
| 거점 | 숭산 자락의 맹 본단. 장경각이 1번 조각을 쥐고 있다 | 장강 하구의 섬 본단. 만금전장 금고가 2번 조각을 쥐고 있다 |
| 명분 | 조각을 모아 마교와 관부로부터 지킨다 | 조각을 모아 정파의 독점을 깬다. 값은 나중에 매긴다 |
| 수업 | 사부 배정(소속 문파 장로), 대련, 경전 강독, 야간 순찰 | 사부 없음. 선배가 후배를 "산다". 도박장, 밀수 당번, 뒷골목 시비 |
| 학우 | 각 문파가 보낸 직전제자. 서열은 매달 비무로 갱신 | 각 방회가 보낸 신예. 서열은 돈과 싸움으로, 매달 바뀐다 |
| 숨은 틀 | 맹주의 측근이 암룡위와 통한다 | 맹의 자금 절반이 관부 돈이다 |

**한 학기의 틀** — 2막까지의 자유 탐험과 달리 3막은 **달력**으로 움직인다. 한 달이 한 장(章)이고, 매달 같은 뼈대 위에 사건이 다르게 얹힌다.
1. 월초 **수업**: 사부/선배가 과제를 낸다. 수련 화면과 같은 구조로, 선택한 무공의 숙련이 오른다.
2. 월중 **사건**: 학우·동료의 개인 사건(14_동료_스토리의 15 사건이 여기로 들어온다), 맹 안의 도난·결투·실종.
3. 월말 **비무회**: 서열전. 순위가 다음 달 사부 선택권, 기숙사, 장경각/금고 출입 권한을 정한다.
4. 밤 **자유 시간**: 기숙사 복도·연무장·뒷산. 동료 호감 사건과 학우 사건, 잠입 조사가 여기서 열린다.

**학원물이 메인 줄기를 끄는 법**
- 조각은 맹 안에 있다(1번 또는 2번). 출입 권한은 서열로 산다. 비무회가 곧 메인 진행이다.
- 학우 중 하나는 암룡위 끄나풀이다. 매달 하나씩 단서가 쌓이고, 플레이어가 지목할 수 있다. 틀리면 그 학우가 맹을 떠나고 서열이 흔들린다.
- 주인공의 옥패를 알아보는 사람이 맹의 가장 늙은 사람(무림맹: 장경각 노승 / 사도맹: 금고지기 노인)이다. 그가 "無極"을 읽는다. 혈통은 여기서 밝혀지고, 맹주는 그것을 알게 된 순간 주인공을 **보호**하는 척 **감금**한다.
- 마지막 달: 맹주가 조각을 황제에게 넘기려 한다(또는 사도맹이면 팔려 한다). 학우들이 편을 가른다. 몇 달 동안 쌓은 서열·호감이 여기서 "누가 주인공 편에 서는가"로 돌아온다. 그 뒤 최종 선택.

**학우(學友)** — 맹마다 다섯. 동료가 아니다. 영입되지 않고 맹에 남는다. 라이벌 하나, 친구 하나, 끄나풀 후보 둘, 선생 쪽 하나. 이름·성격은 [08_인물](08_인물.md)에 추가한다.

**2막과의 이음새**: 2막 마지막 사건이 "맹의 초대장"이다. 정파·사파 양쪽에서 초대가 오고, 성향에 따라 한쪽이 진심이고 한쪽은 함정이다. 14_동료_스토리의 15 사건들은 3막 첫 두 달 안에 배치한다.

**왜 학원물인가**: 1·2막에서 "바깥의 강호"를 떠돌던 주인공이 처음으로 **한곳에 머문다**. 기억이 없는 사람에게 처음 생기는 "소속"이고, 그것을 맹주가 이용한다. 기억은 돌아오지 않지만 이름이 불리는 곳이 생긴다 — 그 상실과 소속의 대비가 3막의 감정선이다.

## 엔딩 분기 기준 [기획]

네 가지의 조합으로 갈린다.

- 정사 성향 (정파/사파/마교)
- 소속 문파 (남은 문파, 또는 직접 세운 문파)
- 인연 (연인·의형제가 누구인지, 동료의 생존 여부)
- 메인 줄기 마지막 사건에서의 핵심 선택
