# 맵

모든 맵은 칸 단위로 걷는 탑다운 지도다. 지도는 글자로 적는 데이터(`Assets/_Project/Data/Regions`)이고, 글자 하나가 한 칸이다.

## 조작 [구현]

| 입력 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| E / Space / Enter | 앞의 NPC에게 말 걸기 |
| Tab / Esc | 수련·정비 메뉴 |
| Shift | 달리기 (경공 필요) |
| F | 도약 (경공 필요) |

## 강호 (큰 지도) [구현]

48×30칸. 산과 숲이 가장자리를 두르고, 강이 세로로 흐르고, 동서로 큰길이 지나고, 강에 다리가 있다.

| 장소 | 위치 | 설명 |
|---|---|---|
| 백로진 입구 | 가운데 | 건물 앞을 밟으면 들어간다. 나오면 들어갔던 자리로 돌아온다 |
| 수풀 지대 (갈대밭) | 서남쪽 | 걸으면 조우한다 |
| 다리 | 큰길 동쪽 | 강을 건넌다 |
| 관도 갈림길 | 큰길 동쪽 끝 | 잠겨 있다. 밟으면 되돌려진다. M2 입구 |

- **피로**: 4걸음마다 +1. 가득 차도 멈추지 않고 45% 느려진다. 마을로 돌아갈 수 있어야 하기 때문이다.
- **조우**: 수풀 지대에서 한 걸음마다 10% 확률로 `갈대밭_도적`.
- **저장**: 강호에서 저장하면 서 있던 칸까지 복원된다.

## 백로진(白鷺鎭) [구현]

32×20칸. 강변의 상업 소도시. 흰 해오라기가 내려앉는 평화로운 나루터 마을처럼 보이지만, 나루터와 장터의 이권은 흑사방이 쥐고 있다.

| 장소 | 있는 것 |
|---|---|
| 청운검문 | 윤백산, 고진악, 토리이 문 |
| 객잔 | 점소이 (숙박 20냥, 소문) |
| 장터 | 장터 상인. 큰길 남쪽. 상점 ([12_아이템](12_아이템.md)) |
| 뒷골목 | 소육 |
| 나루터 | 흑사방 졸개, 흑사방 연락책 |
| 창고 | 창고지기 |
| 흑사방 본거지 | 탁웅 |
| 강 위 섬 | 은둔 노인. 경공 도약으로만 닿는다 |
| 왼쪽 길 끝 | 출구. 강호로 나간다 |

[기획]: 장터의 비단 장수.

## 경공의 맵 효과 [구현]

경공을 하나라도 익히면 켜진다.

- **달리기**: Shift를 누르면 1.8배.
- **도약**: 바라보는 쪽으로 최대 3칸, 가장 멀리 내릴 수 있는 칸에 내린다. 나무, 좁은 물, NPC를 넘고 건물은 못 넘는다. 도약할 때마다 경공 숙련 +5.
- **피로 감소**: 강호에서 6걸음마다 +1.
- **숨은 곳**: 백로진 강 위 섬, 강호의 강은 다리 없이 건널 수 있다.

## 맵 추가 방법

1. `Data/Regions`에 지역맵 에셋을 만들고 `layout`에 글자로 그린다.
2. `tiles`에 글자별 타일을, `npcs`에 인물과 대화를 적는다.
   - `portal`: 밟으면 들어갈 노드
   - `encounterNode`: 밟으면 조우를 굴릴 노드
   - `overlay`: 바닥 위에 겹쳐 그린다
3. `Data/WorldMap.asset`에 노드를 추가하고 강호 지도에 입구 칸을 놓는다.

`ContentTests`가 대화, 전투, 입구 이름이 실제로 있는지 확인한다.
