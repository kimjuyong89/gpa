# 퀘스트

대본은 Ink로 쓴다. `.ink`를 고치면 에디터가 `.json`으로 컴파일한다. 배치 모드에서는 메뉴 **GPA → 대본 컴파일**이나 `InkBuild.CompileAll`을 쓴다.

## 대본 파일

| 파일 | 내용 |
|---|---|
| `Dialogue/Baekrojin.ink` | 최상위. 시작 장면(기억상실), 객잔, 나루터, 소육, 은둔 노인 |
| `Dialogue/Baekrojin_Sects.ink` | 문파 입문과 문하 일거리, 밀수 의뢰 |
| `Dialogue/Baekrojin_Ledger.ink` | 장부 사건 |
| `Dialogue/_externals.ink` | 게임 함수 선언 |

## 메인: 대사형의 장부 (1막) [구현, 내용은 초안]

| 단계 | 내용 | 어디서 |
|---|---|---|
| 1 | 소문: 흑사방 창고에서 대사형을 봤다 | 객잔 점소이 |
| 2 | 단서: "대사형 나리 손님"이 온다 | 나루터 졸개에게 10냥 |
| 3 | 장부 획득 | 창고지기 |
| 완료 | 네 갈래 중 하나, 1막 끝 | 아래 표 |

장부를 얻는 방법: 소육이 주의 끌기 / 창고지기와 전투 / 30냥 뇌물.

장부에는 '無極' 상자가 경사(京師)로 보내졌다고 적혀 있다. 무극진경 4번째 조각의 단서이자 관부의 첫 복선이고, 어느 갈래든 얻는다.

| 갈래 | 상대 | 결과 |
|---|---|---|
| 고발 | 윤백산 | 정파 +2, 청운검문 평판 +3, 윤백산 호감 +3, 흑사방 평판 -5, 대사형 파문. 흑사방 식구면 파문 + 추격 |
| 덮기 | 고진악 | 고진악 호감 +5, 고진악에게 빚 |
| 협박 | 고진악 | 50냥, 사파 +2, 고진악 호감 -5. 장부는 내 손에 남는다 |
| 넘기기 | 탁웅 | 30냥, 사파 +1, 흑사방 평판 +5, 탁웅 호감 +3, 청운검문 몰락 복선 |

## 문파 [구현, 내용은 초안]

| 퀘스트 | 내용 |
|---|---|
| 청운검문 입문 | 입문 동기 문답 → 대사형과 1:1 대련 → 입문. 대련 승패와 상관없다 |
| 청운검문 문하 | 잡일로 공헌 +10, 호감 +1. 청심결 배우기, 직전제자 |
| 흑사방 입문 | 상납금 수금. 주먹(사파 +2) 또는 내 돈 20냥 |
| 흑사방 일거리 | 짐 나르기로 15냥, 공헌 +10, 호감 +1. 음사공 배우기, 직전제자 |
| 밀수 의뢰 | 청운검문 제자만. 30냥, 발각 +40. 세 번째에 들킨다 |

## 그 밖 [구현, 내용은 초안]

| 이벤트 | 내용 |
|---|---|
| 시작: 잃어버린 기억 | 캐릭터 생성 직후. 객잔에서 깨어나 점소이에게 사정을 듣고 낡은 옥패를 받는다. 점소이 호감 +1, 일지 "잃어버린 기억" 1단계. 이후 점소이 첫 방문 인사가 바뀐다 |
| 나루터 흑사방 | 맞서면 정파 +1, 전투. 이기면 10냥, 지면 전낭을 털린다. 돈을 주면 사파 +1 |
| 소육 만남 | 뒷골목에서 소매치기를 붙잡고 국밥을 사 주면 동료 |
| 은둔 노인 | 강 위 섬. 1회 내공 +30, 운리화, 비연단 |
| 장터 상인 | 상점을 연다 |

## 게임 값 키

대본에서 `get`, `add`, `set`으로 쓰는 값이다.

| 키 | 뜻 |
|---|---|
| `정파` `사파` `마교` | 정사 성향 |
| `평판.<문파>` | 평판 |
| `호감.<인물>` | 호감도 |
| `공헌.<문파>` | 공헌도 |
| `발각.<문파>` | 이중 소속 발각 수치 |
| `추격.<문파>` `배신.<문파>` | 추격, 배신 기록 |
| `동료.<이름>` | 1이면 파티 합류 |
| `전투.<id>` | 승리 1, 패배 -1 |
| `장부` | 0 없음, 1 소지, 2 처리함 |
| `단서.무극진경_4` | 4번째 조각 단서 |
| `빚.고진악` `협박.고진악` `대사형_파문` `청운검문_몰락` | 장부 사건 결과 |
| `기연.은둔노인` | 기연을 받았는가 |
| `걸음` `강호.x` `강호.y` | 걸음 수, 큰 지도 위치 |

## 대본 함수

| 함수 | 설명 |
|---|---|
| `get` `add` `set` | 값 읽기·더하기·쓰기 |
| `money` `pay` `earn` | 돈 |
| `give` | 아이템 주기. `give("금창약", 2)` |
| `recruit` `party_full` | 동료 영입. 일행이 가득 차면 거짓을 돌려준다 |
| `rest_inn` `inner_power` | 객잔 휴식, 내공 얻기 |
| `quest` `quest_done` `quest_stage` | 퀘스트 일지 |
| `sect` `join_blocker` `join` `is_disciple` `disciple` `knows` `learn` `secret_job` `expel` | 문파 |

전투는 대사 끝 태그로 요청한다: `# battle: <전투 id>`

상점도 태그로 연다: `# shop: <상점 id>`. 상점을 닫으면 대사가 이어진다.

수련터의 일주천: `# circulate: <Con|Outer|Light>`.
