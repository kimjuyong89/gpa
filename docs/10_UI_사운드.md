# UI · 사운드

UI는 UI Toolkit으로 코드에서 만든다(`Assets/_Project/Scripts/UI`). 테마는 `Art/Resources/UI/Theme.uss`다. 기준 해상도 1280×720.

## 화면 [구현]

| 화면 | 내용 |
|---|---|
| 캐릭터 생성 | 얼굴 4종, 이름, 스탯 분배. 불러오기 |
| 지도 HUD | 이름, 경지, 위치, 돈, 피로, 메뉴 버튼, 조작 안내 |

| 전투 | 좌우 대치, 행동 순서 얼굴, 체력·내력 막대, 상태이상. 무공 / 경공·보법 / 아이템 / 도주를 고르고 그 안에서 고른다. 대상이 여럿이면 눌러 고른다. 머리 위에 방어·회피를 보여 준다 |

| 초식 연마 | 왼쪽 주인공과 초식 이름, 숙달 막대. 오른쪽 네 줄 리듬판 |
| 일주천 | 마음가짐 선택, 좌선 그림 위 경로와 기운, 호흡·화기·산기 막대, 결과 |
| 알림 | 화면 위쪽에 잠깐 뜬다 |

## 개발 패널 [구현]

게임 중 F1로 연다. 지도와 전투에서 열리고, 에디터와 개발 빌드에만 들어간다.

| 구역 | 할 수 있는 것 |
|---|---|
| 주인공 | 돈, 피로, 내공, 내상, 깨달음, 경지, 스탯, 동료 영입·방출 |
| 문파·무공 | 입문, 직전제자, 공헌 +100, 무공 전부 배우기 |
| 아이템 | 장비 전부, 약·영약 전부, 소지품 비우기 |
| 기예 | 기예 전부 +20 (문파·무공 구역) |
| 수련 | 일주천 난이도별, 폐관수련 심마 |
| 운용 심법 | 심법 바꾸기 (문파·무공 구역) |
| 초식 연마 | 무공별 6·9·10성 관문 바로 열기 |
| 전투 | 모든 전투 바로 시작. 전투 중에는 즉시 승리·패배 |
| 대화·상점 | 모든 NPC 대화 |
| 이동 | 지도가 있는 모든 곳 |
| 산중 수련 | 추락 조건 맞추기, 추락 장면 보기, 무명산에 들어가기, 허기·체온 채우기, 자원 +10, 하루 보내기, 강제 하산 |
| 이야기 | 장부를 손에 넣은 상태로 |

새 기능을 만들면 여기에 버튼도 함께 넣는다. 코드는 `Scripts/UI/DevPanel.cs`.

## 전투 연출 [구현]

- 공격자가 상대 쪽으로 달려든다.
- 베기 이펙트, 맞은 쪽이 붉어지며 흔들린다.
- 피해 숫자가 떠오른다. 치명타는 숫자가 커지고 화면이 흔들린다.
- 회피, 상태이상도 글자로 뜬다. 쓰러지면 흐려진다.
- 적은 잠시 뜸을 들인 뒤 행동한다.

## 저장 [구현]

슬롯 1개. 메뉴의 저장 탭에서 한다. 파일은 `Application.persistentDataPath/save.json`이다. 주인공, 게임 값, 퀘스트, 문파, 위치, Ink 진행 상태가 들어간다.

[기획]: 타이틀 화면, 여러 슬롯, 자동 저장.

## 분위기 [구현]

한지, 먹, 주묵. 색은 한지 (233,222,198), 먹 (30,27,24), 주묵 (158,36,28)이다. 수묵 산수를 배경으로, 패널은 한지에 얇은 먹선, 버튼은 붓 획, 강조는 주묵이다.

## 다듬을 것

- 밝은 픽셀 지도와 맵 캐릭터가 수묵 UI와 어울리지 않는다. 지도가 분위기의 다음 과제다.
- 전투 입상은 공격할 때 앞으로 미끄러지고 숨쉬듯 살짝 움직일 뿐, 프레임 애니메이션은 없다.
- 수풀 지대가 격자처럼 반복돼 보인다.
- 길과 풀밭의 경계가 각져 있다.
- 강호 지도에 장소 이름 표시가 없다.
- 실제 키보드·마우스 입력과 연출 속도는 직접 플레이로 확인해야 한다.
