### 성향 프레임 규칙

- 게임 값 `정파` `사파` `마교` 중 가장 높은 것을 따른다. 같으면 정파.
- 루트 요소에 `theme-jade` / `theme-bronze` 클래스를 붙이고, `Theme.uss`에서 `.theme-bronze .btn { background-image: ... }`처럼 덮어쓴다.
- 성향이 바뀌는 순간 바로 바뀐다. 애니메이션은 없다.
- 마교 프레임은 Xianxia 풀팩의 Crimson Moon이지만 사지 않으므로, 당분간 청동을 쓴다.

## 기술 규칙 [구현]

- HD UI 그림은 `Art/Resources/UI/Xianxia/`에 둔다. `PixelArtImport`가 이 폴더는 건너뛰어 bilinear로 들여온다.
- 9-slice는 USS에서 `-unity-slice-left/top/right/bottom`과 `-unity-slice-scale`로 정한다. Sprite Editor의 border는 쓰지 않는다. `-unity-slice-scale`은 `0.4px`처럼 px 단위를 붙여야 한다 (없으면 경고 후 무시).
- 원본 크기와 슬라이스: 버튼 512×160 (112/48, 0.4배), 막대 768×96 (96/32, 0.25배, 채움 영역 x 96~672, y 38~58), 초상 512×512 (안쪽 원 ≈ 400px).
- 초상화는 `.face`에 `border-radius`로 원형 클리핑한다. 사각형 원본 그대로 둔다.
- 픽셀 아이콘은 `Art/Resources/Icons/`에 두고 Point 필터로 들여온다. 54px 등급 프레임 안에 40px로 보여 준다.
- 메뉴 탭은 버튼 프레임 없이 글자 + `rule.png` 밑줄. 선택된 탭만 주묵 밑줄 (`.tab` `.tab-selected`).
- HUD: 초상 원형 + 이름/경지 + 지명 + 엽전 아이콘 금액 + 피로 막대. `TownView.ApplyTheme`가 `사파 > 정파`면 루트에 `theme-bronze`.
- 전투 행동 순서: 다음 차례(두 번째 얼굴)에 `.face-now` 주묵 테두리.
- 생성 그림을 Jianghu 톤에 맞추는 법: 참조 이미지를 넣어 마젠타 배경으로 생성 → BOX 축소 → `palette.png`로 양자화. 임시 스크립트는 `C:\Temp\gpa_mock\post.py`.
- 옛 `btn.png` `btn_hover.png` `btn_off.png`는 참조가 없다. `gen_ink_art.py`에서 생성을 빼도 된다.
