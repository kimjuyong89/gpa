# 대사 편집 가이드

대사는 `Assets/_Project/Dialogue/*.ink` 텍스트 파일이다. 메모장·Notepad++로 열어 고치고 저장하면 Unity가 알아서 다시 컴파일한다. 프로그래밍 지식 없이 고칠 수 있는 범위와, 건드리면 안 되는 줄을 정리했다.

## 어느 파일에 무엇이 있나

| 파일 | 내용 |
|---|---|
| `Baekrojin.ink` | 객잔 점소이, 장터 상인, 나루터 흑사방, 소육, 은둔 노인 |
| `Baekrojin_Sects.ink` | 청운검문·흑사방 입문, 문하 일거리, 밀수 의뢰 |
| `Baekrojin_Ledger.ink` | 대사형의 장부 사건 |
| `Baekrojin_Companions.ink` | 동료 영입 8명 (소육만 `Baekrojin.ink`) |
| `Baekrojin_Mountain.ink` | 무명산 |
| `_externals.ink` | 게임 함수 선언. **고치지 않는다** |

Notepad++를 쓰면 `Tools/ink_notepadpp.xml`을 들여오면(언어 → 사용자 정의 언어 → 가져오기) 고쳐도 되는 줄과 안 되는 줄이 색으로 갈린다.

## 줄의 종류

```ink
=== 객잔_점소이 ===                    ← 장면 이름. 지도 NPC와 연결돼 있으니 바꾸지 않는다
(객잔 안은 국밥 냄새로 가득하다.)         ← 지문. 괄호 안 글은 마음대로
점소이: 어서 옵쇼, 손님!                ← 대사. "이름: " 뒤를 마음대로
+ [소문 좀 들려주시오.]                 ← 선택지. [ ] 안 글을 마음대로
    점소이: 요즘 흑사방 창고가 수상합디다.   ← 선택지 고른 뒤의 대사 (들여쓰기)
    ~ add("호감.점소이", 1)              ← 게임 값 조작. 건드리지 않는다
    -> END                              ← 장면 끝. 건드리지 않는다
+ {money() >= 5} [국밥 한 그릇. (5냥)]   ← { } 는 조건. [ ] 안 글만 고친다
* [한 번만 나오는 선택지]                ← *는 한 번 고르면 사라진다. +는 매번 나온다
```

## 마음대로 고쳐도 되는 것

- `이름: ` 뒤의 대사 전부
- `( )` 지문
- `[ ]` 선택지 글
- 대사 줄을 더 넣거나 빼는 것 (같은 들여쓰기로)
- 대사 순서 바꾸기

## 건드리면 안 되는 것

| 기호 | 뜻 | 왜 |
|---|---|---|
| `~ ...` | 돈·호감·동료·퀘스트를 바꾸는 줄 | 게임 진행이 걸려 있다 |
| `{ ... }` | 조건 (돈이 있는지, 동료인지) | 괄호 짝이 깨지면 컴파일이 안 된다 |
| `-> 이름` `-> END` | 다음 장면으로 가기 | 빠지면 대화가 멈추거나 다음 장면으로 흘러 넘친다 |
| `=== 이름 ===` `= 이름` | 장면 이름 | 지도 NPC·다른 대본이 이 이름으로 부른다 |
| `# battle: ...` `# shop: ...` | 전투·상점 열기 | 데이터 id다 |
| `temp`, `else`, `-` 로 시작하는 줄 | 분기 구조 | |
| 화자 이름 (`점소이:` `소육:`) | 얼굴·초상 연결 | 이름을 바꾸면 얼굴이 안 뜬다. 새 인물은 아래 참고 |

## 자주 하는 일

**대사 한 줄 추가**: 같은 들여쓰기로 끼워 넣는다. 한 줄이 한 번 클릭이다.

```ink
소육: 돈은 돌려줄게.
소육: 대신 밥 한 끼만 사 주면 안 돼?      ← 새로 넣은 줄
```

**긴 대사**: 한 줄에 쓰면 화면에서 자동 줄바꿈된다. 두 번 클릭으로 나누고 싶으면 두 줄로 쓴다.

**선택지 추가 (아무 효과 없는 잡담)**:

```ink
+ [날씨가 좋군.]
    점소이: 그렇습죠. 손님.
    -> END
```

선택지 뒤 줄은 네 칸 들여쓰고, 마지막에 `-> END`를 꼭 둔다. 기존 선택지 하나를 통째로 복사해서 고치는 게 가장 안전하다.

**호감에 따라 다른 인사**: 기존 장면 첫 줄의 패턴을 복사한다.

```ink
{get("호감.소육") >= 5:
    소육: 왔어? 기다렸잖아.
- else:
    소육: 뭐야, 너냐.
}
```

콜론·대시·중괄호 위치만 그대로 두고 대사만 바꾼다.

**주인공이 말하기**: 화자를 `주인공:`으로 쓴다. 화면에는 플레이어가 정한 이름과 얼굴이 나온다.

```ink
주인공: 그 상자, 어디로 갔습니까?
```

**다른 사람 대사 안에서 주인공 이름 부르기** ("어이, 철수!"): 아직 안 된다. [기획]

## 저장 뒤 확인

1. 저장하면 Unity가 몇 초 안에 다시 컴파일한다. Unity 콘솔에 빨간 줄이 없으면 된다. (배치 모드면 메뉴 **GPA → 대본 컴파일**)
2. 플레이 → **F1** 개발 패널 → "대화·상점"에서 NPC 이름을 누르면 그 장면이 바로 열린다. 처음부터 걸어갈 필요 없다.
3. 자주 나는 오류
   - `Expected ... }`: 중괄호 `{ }` 짝이 안 맞는다. 대사에 `{` `}`를 쓰지 않는다.
   - `Unexpected end of choice`: 선택지 뒤에 `-> END`가 빠졌다.
   - 선택지가 안 보인다: `+` 앞 들여쓰기가 다른 선택지와 다르다. 같은 묶음은 같은 칸에 둔다.
   - `Divert target not found`: `->` 뒤 장면 이름에 오타.

## 새 인물을 말하게 하기

대사에 새 이름을 쓰면 글은 나오지만 얼굴이 안 뜬다. 얼굴을 붙이려면 두 가지가 필요하다.

- `Art/Resources/Portraits/<이름>.png` (초상)
- `Scripts/UI/DialogueBox.cs`의 `Faces` 표에 `["이름"] = "픽셀 얼굴 폴더"`

이름만 알려 주면 넣는다. 이름 없는 단역(지나가는 사람)은 지문 `( )`으로 처리하면 된다.
