## 표기

- **[구현]**: 게임에 들어가 있다.
- **[기획]**: 정해졌지만 아직 게임에 없다.
- **[초안]**: 게임에 있지만 이름·내용이 바뀔 수 있다.
- 수치는 밸런스용 임시값이다. 표에 적힌 수치는 코드와 데이터에서 옮긴 값이다.

## 관리 규칙

- 기획이나 수치가 바뀌면 해당 문서를 같이 고친다.
- 수치의 원본은 게임 데이터다. 문서와 다르면 데이터가 맞고, 문서를 고친다.
  - 무공: `Assets/_Project/Data/MartialArts`
  - 문파: `Assets/_Project/Data/Sects`
  - 전투: `Assets/_Project/Data/Battles`
  - 지도: `Assets/_Project/Data/WorldMap.asset`, `Assets/_Project/Data/Regions`
  - 대본: `Assets/_Project/Dialogue`
- 아직 정하지 않은 것은 [11_로드맵](11_로드맵.md)에 모은다.
